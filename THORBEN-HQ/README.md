## Grundregeln
- Änderungen erfolgen in kleinen, nachvollziehbaren Updates.
- Vor größeren Änderungen wird ein Sicherungs-Branch erstellt.
- Secrets gehören ausschließlich in geschützte GitHub Secrets oder sichere Server-Umgebungsvariablen.
- Keine API-Schlüssel in App-Code, Git-Historie, Logs oder Chatnachrichten.
- Builds gelten erst nach erfolgreichem CI-Lauf als gebaut; Geräteinstallation muss separat geprüft werden.
- Automatisierungen benötigen minimale Rechte und explizite Freigabe für externe oder destruktive Aktionen.
